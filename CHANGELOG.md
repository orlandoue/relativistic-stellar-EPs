# Changelog

## Revision R3 (prepared for resubmission)

### Corrected: working precision of the constants in `audit_appendixB.py`

`audit_appendixB.py` previously built its constants at module level:

```python
V0  = mpf('25.25')
K   = mpf(5)
TAU = mpf('0.03')
```

`mp.dps` was only raised to 30 inside `if __name__ == "__main__"`, i.e. *after*
those lines had run. `mpf('...')` binds a value at whatever precision is current
when it is evaluated, so all three were parsed at the mpmath default of 15
digits. `25.25` and `5` are exactly representable in binary and were unaffected;
`0.03` is not. The script therefore solved the pencil for a relaxation time
differing from 3/100 in the 17th significant digit.

Consequence: the bordered-Newton solve converged, with residuals at the roundoff
floor, to a point about 8×10⁻¹⁷ away from the true sector-0 EP2, and this offset
did not shrink when N, the working precision d, or the iteration count were
increased. The saturation at 16 forward digits was an artefact of the literal,
not a conditioning ceiling.

**Fix.** All constants are now built by `set_precision(d)`, which raises `mp.dps`
and rebuilds V₀ = 101/4, k = 5 and τ = 3/100 as exact rationals at that
precision. A closed-form reference for the sector-0 EP2 was added
(`exact_ep2()`): eliminating ζ₀ between P₀ = 0 and ∂ₛP₀ = 0 leaves

    2 τ s³ + (1 + τ) s² − V₀ = 0        ⇔   6 s³ + 103 s² − 2525 = 0

whose relevant root is

    s*     = −6.192565050794292749610955930078711757432…
    ζ₀*    =  7.547876432887540125414130906329316922389…
    y*     =  1.2385130101588585499…      Λ* = 1.5095752865775080251…

matching all twenty digits published in Table 1.

**Corrected audit output** (five Newton seeds perturbed at the seventh digit;
the last one to two units of each count fluctuate because the terminal residual
sits at the roundoff floor):

| N (d = 30) | residual | κ₂(J) | forward digits, s\* | a-priori bound |
|---|---|---|---|---|
| 24 | 2×10⁻²⁹–3×10⁻²⁸ | 5.45×10¹² | ≈ 21 | 19–20 |
| 32 | 2×10⁻²⁹–2×10⁻²⁸ | 3.34×10¹⁴ | ≈ 20 | 18–19 |
| 40 | 2×10⁻²⁹–2×10⁻²⁸ | 7.67×10¹⁵ | ≈ 18 | 17–18 |

| 40 | ≈ 31 |

Two things follow, both now stated in Appendix B of the manuscript. Since the
collocation is exact on the polynomial sector, the discretisation error is
identically zero and the whole deviation is arithmetic; the forward accuracy
therefore *degrades* with N, tracking κ₂(N), and the a-priori bound
κ₂‖F‖/‖J‖ is tight to about one digit at every resolution. At fixed N the
accuracy tracks the working precision one-for-one.

This is independently corroborated by `hyperboloidal_pencil.py`, which builds τ
after raising `mp.dps` and was therefore never affected: its block [C] already
returned ζ₀* = 7.547876432887540125414 and s* = −6.192565050794292749609 at
N = 24, i.e. 21–22 correct digits.

Only `audit_appendixB.py` was affected. `bordered_newton_robustness.py`,
`cqg_core.py` and `hyperboloidal_pencil.py` have no module-level constants;
`branches_Ap_B.py`, `eigenvector_overlap.py`, `diagnostic_dense_continuation.py`
and `defective_crossings_proof/03_*.py` build theirs after `mp.dps` is set.

### Corrected: nomenclature

Residual occurrences of "diabolic" — including a message printed at runtime by
`bordered_newton_robustness.py` — replaced by "defective". The crossings of
Eq. (51) are algebraically double but geometrically simple, i.e. Jordan blocks,
not diabolic (semisimple) points; the manuscript uses "defective" throughout.

### Corrected: branch R2 description

The README described ζ₀* along branch R2 as decreasing in η, which is true only
over the first two archived points. Over the full archived range η ∈ [0.05, 0.25]
it is not monotone (4.993, 4.791, 4.854, 5.407, 6.128). This matches the
manuscript, which declines to attribute a parent to R2.

### Corrected: eigenvector-overlap range

README quoted 0.9987–0.9999; the archived extremes are 0.998707 and 0.999989,
so the manuscript's 0.9987–0.99999 is the correct rounding.

### Corrected: the stated precision of the archived continuation data

The README previously said that continuation values were "truncated to 7
significant figures on purpose", and described `robustness_continuation.json` as
the truncated form of the solver's raw output. Neither was true of that file: it
stores 24–26 decimals per entry throughout (`rama1`, `rama_compleja`, `rama2`,
and most of `cusp`). The manuscript's Data availability statement had inherited
the same incorrect claim.

Both have been rewritten to describe what is actually archived: values are stored
at the working precision of the run, and the digits **quoted in the manuscript**
are rounded to the forward accuracy the bordered-Jacobian conditioning supports —
roughly 7 significant figures for a continuation point. The archive is
deliberately *not* truncated to that accuracy, so that the rounding can be
checked rather than assumed. Readers should not treat the archived digits as
certified; only the leading ones are.

### Scope corrections in the manuscript

Four statements were narrowed to match what is actually proved or evaluated:

- the abstract and introduction now say **complete quasinormal *point* spectrum**,
  in the aligned realization and on the polynomial core, and state explicitly that
  absence of essential spectrum for a closed extension is neither claimed nor needed;
- the criterion is stated as $(v_{FR}/v_\beta)^2 \ge 1 + \Theta(\gamma)$, with
  $v_{FR} \gtrsim 3 v_\beta$ identified as its weak-radiation value. The exact
  factor at the fiducial $\gamma_{GW} = 0.03$ is $\sqrt{1+7.596} = 2.93$;
- "every dense-matter transport calculation to date" became "the dense-matter
  transport calculations examined here", which is what the paper evaluates;
- the equivalence between Israel–Stewart causality and $v_{FR} \le c$ is now
  scoped to the linear, single-bulk-channel closure, citing the nonlinear
  constraints of Cordeiro et al.

The convention for $\rho$ is now stated where the symbol is first defined and
again where the Mandelstam–Leontovich form is introduced, together with the
already-present demonstration that the choice is immaterial.
